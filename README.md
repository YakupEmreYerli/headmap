# Headmap

See a page's **title**, **meta description**, **canonical**, **robots** and **H1–H6 outline**
at a glance, and copy all of it in one click. A small browser extension for Brave, Chrome and Edge.

## Install (unpacked)

1. Open `brave://extensions` (or `chrome://extensions`).
2. Turn on **Developer mode**.
3. **Load unpacked** → pick this folder.
